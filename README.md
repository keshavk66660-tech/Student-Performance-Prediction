# Student Performance Prediction System

## About
A machine learning mini project that predicts student performance using attendance, study hours, previous marks, and assignment scores.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Streamlit

## Features
- Student performance prediction
- Data visualization
- Performance analysis
- Interactive Streamlit dashboard
- Identification of students who may need additional academic support

## How to Run
1. Install Python.
2. Install the required packages: `pip install streamlit pandas numpy matplotlib seaborn scikit-learn joblib`
3. Run: `streamlit run app.py`

## Note
This project currently uses synthetic/demo data. Predictions should be validated using real student data before making academic decisions.
